Metadata Reader

💡 How to read metadata ▾
Extract and display metadata embedded in image files. Upload an image file (JPEG recommended for EXIF data). The system reads standard metadata tags including camera make and model, GPS coordinates, date and time, image dimensions, colour profile, and any embedded thumbnails. This tool is useful for verifying image origin, checking for editing history, and extracting location data from photographs. ⚠️ Important: Download the metadata report before navigating away. Use the Download button to save in PDF, DOCX, JSON, CSV, TXT, XML, or HTML format.

Reads EXIF, dimensions, format, and color mode. All processing in pure JavaScript.
