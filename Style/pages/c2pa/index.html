C2PA Content Provenance

💡 How to read C2PA provenance ▾
Read C2PA (Coalition for Content Provenance and Authenticity) data from an image. Upload an image file that contains C2PA provenance metadata. The system parses the C2PA manifest and displays the digital signature, content credentials, editing history, and any claims made by the content creator. Use this tool to verify the origin and editing history of images from C2PA-compatible cameras and editing software. ⚠️ Important: Download the C2PA report before navigating away. Save it in PDF, DOCX, JSON, or HTML format.

Read C2PA content provenance metadata from images. Displays manifests, assertions, actions, ingredients, and signature info.

✍️ How to sign with C2PA ▾
Add C2PA provenance data to an image, creating a verifiable content credential. Upload an image and provide creator information such as name, organisation, and assertions about the content. Select a content type (artwork, news, photography, etc.) to categorise the credential. The system creates a C2PA manifest and signs it using an ECDSA key embedded in your browser. The signed image can be shared with others, who can verify its provenance using the C2PA read tool. ⚠️ Important: Download the C2PA-signed image before navigating away. You can also save the manifest in JSON format.

🔍 How to verify a C2PA signature ▾
Verify the cryptographic signature of a C2PA-provenanced image. Upload a C2PA-signed image. The system extracts the manifest and validates the ECDSA signature against the embedded public key. It also checks the integrity of the metadata and reports any tampering. A successful verification confirms the image has not been altered since its C2PA credentials were created. ⚠️ Important: Download the verification report before navigating away. Save it in PDF, DOCX, JSON, or HTML format.
