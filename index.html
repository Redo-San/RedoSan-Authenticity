About RedoSan Authenticity

RedoSan Authenticity is an open-source digital authenticity tool that runs entirely in your browser. No files are ever uploaded to any server — all processing happens client-side.

We provide a comprehensive suite of tools for digital forensics and media verification:

  • Watermarking — 9 algorithms including LSB, DCT, DWT, neural-style, and forensic watermarking
  • Fingerprinting — Cryptographic hashing (SHA-1/2/3, BLAKE2/3, MD5, RIPEMD-160, Whirlpool) and perceptual image hashing
  • Metadata — Read EXIF, dimensions, format, and color mode from images
  • Timestamping — SHA-256 hashing with OpenTimestamps verification support

Built with privacy as a core principle. Your files never leave your device.

←

Privacy Policy

Your data stays on your device. RedoSan Authenticity is a 100% client-side application. All processing is done in your browser using JavaScript. No files, metadata, or any other data are transmitted to any server.

What we collect

Nothing. We do not collect, store, or transmit any personal data, files, or analytics. The application runs entirely on GitHub Pages and no backend server is involved.

Third-party libraries

We load JavaScript libraries from CDNs (cdnjs and jsdelivr) for PDF and DOCX export functionality. These CDNs may have their own logging and analytics. No data from your files is shared with these services.

Changes

This policy may be updated occasionally. Continued use of the tool constitutes acceptance of the current policy.
